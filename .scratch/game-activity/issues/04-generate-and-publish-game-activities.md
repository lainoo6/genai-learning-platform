# 04: Generate and publish editable Game Activities

**What to build:** Lesson generation creates a structured, lesson-grounded Game Activity draft with five Challenges by default; instructors can edit all content and answer metadata; publication is blocked for invalid, ambiguous, incomplete, inaccessible, or mixed-locale content.

**Blocked by:** 01: Build the foundational Game Activity with Sort Challenges; 02: Add Match and Choose Challenge formats; 03: Add instructional feedback, hints, replay, and accessible interaction states.

**Status:** ready-for-agent

- [x] Generate Sort, Match, and Choose Challenges from lesson objectives and source content with deterministic answer keys.
- [x] Generate required correct/incorrect feedback, optional Hints, and plausible Distractors in the lesson locale.
- [x] Allow instructors to edit the generated Challenge content, answer metadata, feedback, and Hints before publication.
- [x] Fail visibly for invalid, ambiguous, incomplete, inaccessible, or mixed-locale generation and block publication until validation passes.
