# 06: Add approved supporting media to Game Activities

**What to build:** Instructors can attach or approve model-generated images and brief animations as optional Supporting media without making learning-critical content inaccessible or dependent on media.

**Blocked by:** 04: Generate and publish editable Game Activities.

**Status:** complete

- [x] Require instructor approval, safety/moderation checks, provenance metadata, and editable alt text or a decorative designation for generated images.
- [x] Keep the text learning path complete when media is unavailable.
- [x] Make animations optional, skippable, non-blocking, and capped at five seconds with no timing-based success condition.
- [x] Prevent media from being the sole answer key, option distinction, Correction, Hint, or feedback source.
